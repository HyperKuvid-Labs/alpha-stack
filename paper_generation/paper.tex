\begin{abstract}
AlphaStack is a novel approach to autonomous code generation, integrating multi-agent reasoning and sandboxed execution to iteratively write, build, test, and correct software projects from natural language descriptions. This paper details the system's 7-phase generation pipeline and its specialized Planning and Correction agents, which operate in tandem to resolve errors through dynamic Docker environments. We demonstrate AlphaStack's efficacy across multiple programming languages and complex domains, achieving high success rates on challenging evaluation benchmarks. Our system eliminates the need for manual human intervention during development, bridging the gap between high-level requirements and robust, tested code.
\end{abstract}

\section{Introduction}
Large Language Models (LLMs) have demonstrated remarkable capabilities in code generation, yet they frequently fail to produce functionally correct, syntactically valid codebases for non-trivial applications. Traditional approaches either lack a mechanism for iterative refinement or rely on lightweight interpreters that cannot simulate complex, multi-file software environments. In this work, we introduce AlphaStack, an end-to-end multi-agent framework that translates natural language prompts into complete, reliable software systems. By adopting a "generate, build, test, and correct" loop grounded in isolated Docker containers, AlphaStack ensures that the final output is not only written but demonstrably functional.

\section{Methodology}
The AlphaStack system employs a 7-phase generation pipeline that orchestrates code generation and dependency management, followed by an iterative AI Planner Agent loop for testing and error correction.

\begin{enumerate}
    \item \textbf{Software Blueprinting:} Transforms the natural language prompt into a structured JSON definition mapping files, modules, and roles.
    \item \textbf{File Generation:} LLM instantiation of actual code based on the blueprint.
    \item \textbf{Dockerfile Generation:} Creates production-ready, language-appropriate Docker instructions.
    \item \textbf{Dependency Analysis:} Performs static analysis on generated code to construct an internal import and dependency graph.
    \item \textbf{Dependency File Generation:} Generates package configuration files (e.g., \texttt{requirements.txt}, \texttt{package.json}, \texttt{Cargo.toml}).
    \item \textbf{Dependency Resolution:} Validates generated dependency files.
    \item \textbf{Docker Testing Pipeline:} An AI Planner orchestrator enters a loop to iteratively build the Docker image, run tests, analyze logs, and dispatch a Corrector sub-agent to apply fixes until both build and tests succeed.
\end{enumerate}

\section{Results}
We evaluated AlphaStack on a custom benchmark suite containing 40 challenging programming tasks across four languages: CUDA, Go, Rust, and TypeScript. The performance was assessed using standard LLMs alongside leading proprietary and open-weight models.

\section{Conclusion}
AlphaStack represents a significant step toward fully autonomous software engineering. By seamlessly integrating an LLM-driven multi-agent framework with robust, sandboxed Docker validation, the system effectively resolves build and runtime errors without human intervention. Future work will expand the evaluation suite, integrate additional programming languages, and explore performance optimizations for complex multi-container environments.
